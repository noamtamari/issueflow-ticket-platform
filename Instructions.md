# Instructions

This repository contains the IssueFlow backend home assignment.

## Stack

- TypeScript
- NestJS
- PostgreSQL
- JWT authentication
- Jest / Supertest for testing

## AI-Assisted Development

AI tools were used to support planning, implementation review, test planning, and documentation.

Tools used:
- Claude Opus 4.7 via Claude Code
- GitHub Copilot CLI with GPT-5.2 Codex

All generated suggestions were reviewed, adjusted when needed, and validated by tests.

## Development Rules

- Follow the existing NestJS module structure.
- Keep controllers thin.
- Put business logic in services.
- Use DTOs and validation for API input.
- Protect required endpoints with JWT authentication.
- Add or update tests when behavior changes.
- Do not introduce unnecessary dependencies.
- Keep documentation updated.
